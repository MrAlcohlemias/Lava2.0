# Lava2.0

Propuesta de rediseño para LAVA 2.0 DETAILING. Web estática en HTML, CSS y JavaScript, sin instalación ni backend.

## Abrir
Abre index.html en tu navegador. También puedes ejecutar `python -m http.server 8080` en esta carpeta y visitar http://localhost:8080.

## Contenido y funciones
- Diseño adaptable a móvil y escritorio, negro, rojo y blanco cálido.
- Servicios de la web original; sin precios inventados.
- 28 fotos de trabajos en una galería filtrable, ampliable y navegable por teclado.
- Testimonios existentes presentados como extractos, sin estrellas ni calificaciones inventadas.
- Teléfono, correo, Instagram, WhatsApp, dirección y horarios conservados.
- Formulario que prepara un mensaje de WhatsApp. No envía nada automáticamente ni confirma reservas; no almacena datos.
- Menú móvil, enlaces telefónicos y acceso a indicaciones en Google Maps.
- Fuentes e imágenes locales. Sin dependencias de desarrollo.
